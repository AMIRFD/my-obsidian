

راهنمای همگام‌سازی Obsidian با GitHub از طریق Git Vault Sync


# ۱ هدف و پیش‌نیازها

این راهنما مراحل ذخیره و همگام‌سازی یادداشت‌های Obsidian Desktop را در یک مخزن خصوصی GitHub با افزونهٔ **Git Vault Sync** توضیح می‌دهد. در پایان، افزونه به مخزن متصل می‌شود و می‌توانید یادداشت‌ها را به‌صورت دستی یا خودکار همگام‌سازی کنید. این افزونه برای کارکردن به نصب جداگانهٔ برنامهٔ Git نیاز ندارد و از اتصال HTTPS به مخزن استفاده می‌کند؛ جزئیات قابلیت‌ها و تنظیمات در [مستندات Git Vault Sync](https://www.obsidianstats.com/plugins/git-vault-sync) آمده است.

پیش‌نیازها: حساب GitHub، یک Vault در Obsidian Desktop، اتصال اینترنت و دسترسی به تنظیمات افزونه‌های Obsidian. نام کاربری GitHub و نام دقیق مخزن را در دسترس داشته باشید. روند کلی چنین است: ساخت مخزن خصوصی، ساخت توکن محدود به همان مخزن، نصب افزونه، واردکردن مشخصات اتصال و اجرای نخستین همگام‌سازی.

# ۲ ۱. ساخت مخزن خصوصی در GitHub

۱. وارد [GitHub](https://github.com/) شوید. از دکمهٔ **+** در بالای صفحه، **New repository** را انتخاب کنید. ۲. در **Repository name** نامی روشن و کوتاه وارد کنید؛ برای نمونه obsidian-vault. حروف کوچک و خط تیره (-) انتخابی خوانا و رایج است. نام مخزن می‌تواند حروف لاتین، عدد، نقطه، خط تیره و زیرخط داشته باشد؛ جزئیات در [راهنمای ساخت مخزن GitHub](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository) ذکر شده است. ۳. در بخش **Visibility** گزینهٔ **Private** را انتخاب کنید تا مخزن عمومی نباشد. در صورت تمایل توضیح کوتاهی بنویسید. ۴. اگر می‌خواهید مخزن را به یک Vault موجود وصل کنید، بهتر است مخزن را بدون README، فایل .gitignore یا مجوز اولیه بسازید تا محتوای اولیهٔ مخزن با فایل‌های محلی تداخل نکند. برای مخزن کاملاً تازه می‌توانید README را انتخاب کنید. ۵. روی **Create repository** بزنید. صفحهٔ مخزن را باز نگه دارید؛ نشانی HTTPS آن را در تنظیمات افزونه وارد خواهید کرد.

# ۳ ۲. ساخت توکن دسترسی محدود و امن
توکن دسترسی شخصی (PAT) مانند رمز عبور است؛ آن را در اختیار دیگران نگذارید. GitHub استفاده از توکن‌های **fine-grained** را در صورت امکان توصیه می‌کند، چون دسترسی را می‌توان به یک مخزن و مجوزهای مشخص محدود کرد. [راهنمای GitHub دربارهٔ توکن‌ها](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) و مستندات افزونه، برای این کاربرد دسترسی **Contents: Read and write** روی همان مخزن را پیشنهاد می‌کنند.

۱. در GitHub روی تصویر حساب کاربری بزنید و وارد **Settings** شوید. در نوار کناری به **Developer settings → Personal access tokens → Fine-grained tokens** بروید و **Generate new token** را انتخاب کنید. اگر صفحه را گم کردید، [صفحهٔ توکن‌های GitHub](https://github.com/settings/tokens) راه میان‌بر است. ۲. برای **Token name** نامی مانند obsidian-vault-sync انتخاب کنید و برای **Expiration** تاریخ انقضا تعیین کنید. ۳. در **Repository access** گزینهٔ **Only select repositories** را بزنید و فقط مخزن ساخته‌شده را انتخاب کنید. ۴. در **Repository permissions**، برای **Contents** سطح **Read and write** را تعیین کنید؛ مجوزهای غیرضروری را اضافه نکنید. سپس **Generate token** را بزنید. ۵. توکن را همان لحظه کپی و در محل امن نگه دارید. اگر گم شود، معمولاً باید توکن تازه بسازید؛ توکن را در سند، تصویر یا پیام عمومی ذخیره نکنید.

اگر توکن قبلی با خطای احراز هویت روبه‌رو شده، ابتدا مخزن انتخاب‌شده و مجوز **Contents: Read and write** را بررسی کنید. برای این اتصال، توکن محدودشده به مخزن را بر توکن Classic با دسترسی گسترده ترجیح دهید.

# ۴ ۳. نصب Git Vault Sync در Obsidian Desktop

۱. در Obsidian از آیکون چرخ‌دنده وارد **Settings** شوید و **Community plugins** را باز کنید. اگر افزونه‌های اجتماعی خاموش‌اند، آن‌ها را فعال کنید. ۲. روی **Browse** بزنید، Git Vault Sync را جست‌وجو کنید و افزونه را با همین نام انتخاب کنید. ۳. **Install** و سپس **Enable** را بزنید. ۴. صفحهٔ تنظیمات افزونه را از **Settings → Git Vault Sync** باز کنید.

نصب از فهرست افزونه‌های اجتماعی، روش پیشنهادی مستندات افزونه است. در رایانهٔ رومیزی، موتور **Git** افزونه از تاریخچهٔ محلی و ادغام تغییرات پشتیبانی می‌کند؛ تنظیم **Sync engine** روی **Auto** معمولاً انتخاب مناسبی است.

# ۵ ۴. اتصال والت به مخزن و نخستین همگام‌سازی

در تنظیمات **Git Vault Sync**، اطلاعات اتصال را وارد کنید:

•              **Remote URL:** نشانی HTTPS مخزن، با قالب https://github.com/نام‌کاربری/نام‌مخزن.git. از دکمهٔ **Code** در صفحهٔ مخزن، نشانی HTTPS را کپی کنید.

•              **Branch:** نام شاخهٔ مخزن؛ معمولاً main است. اگر شاخهٔ اصلی را با نام دیگری ساخته‌اید، همان نام را وارد کنید.

•              **Username:** نام کاربری GitHub، نه نشانی ایمیل.

•              **Personal Access Token:** توکنی که در گام قبل ساختید.

•              **Author name / email:** نام و ایمیلی که می‌خواهید در مشخصات ثبت تغییرات (commit) درج شود.

اگر Vault از قبل فایل دارد و هنوز مخزن Git ندارد، از گزینهٔ **Initialize** در تنظیمات افزونه استفاده کنید؛ طبق مستندات، این کار مخزن محلی را راه‌اندازی، Remote را وصل، تغییرات دوردست را دریافت و شاخه را بررسی می‌کند. اگر مخزن روی GitHub از پیش فایل اولیه‌ای مانند README دارد، ممکن است هنگام ادغام تغییرات با فایل‌های محلی تداخل پیش بیاید؛ پیام افزونه را بخوانید و در پنجرهٔ تعارض، نسخهٔ مناسب را برای هر فایل انتخاب کنید.

برای آزمون اتصال، از Command Palette دستور **Git Vault Sync: Test connection to remote** را اجرا کنید. سپس دستور همگام‌سازی یا دکمهٔ **Sync now** را بزنید. پیام **Vault is ready** نشان می‌دهد راه‌اندازی والت آماده شده است؛ برای اطمینان از انتقال فایل‌ها، اجرای Sync و مشاهدهٔ وضعیت موفق را نیز بررسی کنید.

# ۶ ۵. همگام‌سازی خودکار و رفع خطاهای رایج

در تنظیمات افزونه می‌توانید **Sync on startup** را برای همگام‌سازی هنگام بازشدن Obsidian و **Auto-sync on a timer** را برای همگام‌سازی دوره‌ای فعال کنید. فاصلهٔ زمانی را متناسب با دفعات تغییر یادداشت‌ها انتخاب کنید؛ برای شروع، ۱۰ دقیقه فاصلهٔ معقولی است. همگام‌سازی خودکار فقط وقتی برنامه در حال اجرا و دستگاه آنلاین است انجام می‌شود.

اگر آزمون اتصال ناموفق بود، این موارد را به‌ترتیب بررسی کنید: نشانی HTTPS و نام مخزن درست است؛ **Username** نام کاربری دقیق GitHub است؛ توکن منقضی یا لغو نشده؛ توکن به مخزن درست محدود شده و مجوز **Contents: Read and write** دارد؛ و شاخهٔ انتخابی وجود دارد. پس از اصلاح تنظیمات، آزمون اتصال را دوباره اجرا کنید.

**نکتهٔ امنیتی مهم:** طبق مستندات افزونه، توکن در فایل data.json افزونه و روی دیسک به‌صورت متن ساده نگه‌داری می‌شود. خود افزونه این فایل را از همگام‌سازی خودش کنار می‌گذارد؛ اما اگر همین Vault را با مخزن Git دیگری نیز ردیابی می‌کنید، مسیر .obsidian/plugins/git-vault-sync/data.json را به .gitignore آن مخزن اضافه کنید تا توکن ناخواسته منتشر نشود. از توکن محدود به یک مخزن و دارای تاریخ انقضا استفاده کنید؛ اگر احتمال افشای آن وجود داشت، توکن را در GitHub لغو و توکن تازه‌ای ایجاد کنید.

# تعریف پروژه

این سند راهنمای کامل اتصال نرم‌افزار یادداشت‌برداری Obsidian به مخزن خصوصی GitHub است؛ هم روی کامپیوتر (نسخه لوکال دسکتاپ) و هم روی گوشی اندروید، از طریق افزونه مشترک **Git Vault Sync**. علاوه بر همگام‌سازی دوطرفه، هدف دوم پروژه این است که از تمام نودها، پوشه‌ها و فایل‌های .md ولت به‌صورت خودکار و دوره‌ای بکاپ گرفته شود تا در صورت حذف تصادفی داده‌ها، تاریخچه کامل در GitHub باقی بماند. در پایان، روش محدود کردن اوبسیدینِ موبایل به دسترسی فقط-خواندنی (Read-only) نیز مستند شده است.

# ۲ خلاصه پروژه

## ۲.۱ خلاصه و مفهوم

کلیت کار به این صورت است که پوشه Vault اوبسیدین (شامل همه پوشه‌ها و فایل‌های .md) به یک مخزن خصوصی GitHub متصل می‌شود. روی دسکتاپ، افزونه Git Vault Sync با موتور کامل Git عمل Stage، Commit، Merge و Push را انجام می‌دهد و با تنظیم گزینه‌های **Sync on startup** و **Auto-sync on a timer** (مثلاً هر ۵ تا ۱۰ دقیقه) هر تغییری به‌طور خودکار به GitHub ارسال و از آن دریافت می‌شود. روی اندروید همان افزونه با موتور سبک‌تر GitHub API کار می‌کند و فایل‌ها را یک‌به‌یک منتقل می‌کند تا حافظه گوشی تحت فشار قرار نگیرد. چون هر Push در واقع یک Snapshot با تاریخچه Git است، در عمل یک **بکاپ خودکار و نسخه‌دار** از تمام یادداشت‌ها خواهیم داشت که حتی تغییرات و حذف‌های قبلی را نیز نگه می‌دارد.

# ۳ نقشه پروژه

معماری پروژه از پنج جزء تشکیل شده است:

|جزء|نقش در نقشه|
|---|---|
|Obsidian دسکتاپ|محیط اصلی کار؛ ویرایش کامل یادداشت‌ها و منشأ تغییرات|
|افزونه Git Vault Sync (دسکتاپ)|موتور Git کامل (isomorphic-git)؛ همگام‌سازی و بکاپ خودکار بدون نیاز به نصب Git جداگانه|
|مخزن خصوصی GitHub|نقطه مرکزی همگام‌سازی و محل ذخیره تاریخچه بکاپ‌ها|
|Obsidian اندروید + Git Vault Sync (موبایل)|دریافت تغییرات از GitHub و (در صورت مجاز بودن) ارسال تغییرات گوشی|
|Personal Access Token (PAT)|اعتبارسنجی هر دو دستگاه به GitHub از طریق HTTPS|

مسیر جریان داده: تغییر در دسکتاپ ← Push خودکار به GitHub ← Pull در اندروید (و برعکس). موتور GitHub Data API موبایل همیشه پوشه تنظیمات .obsidian/ را رد می‌کند و فقط یادداشت‌ها را همگام می‌کند؛ موتور Git دسکتاپ می‌تواند در صورت عدم حذف آن را نیز سینک کند.

# ۴ تعریف نحوه کار هر نود

در این بخش هر «نود» به معنای یکی از اجزای نرم‌افزاری زنجیره همگام‌سازی و بکاپ است.

## ۴.۱ نود Git Vault Sync (دسکتاپ):

نود شروع‌کننده و موتور اصلی بکاپ روی کامپیوتر است. پس از نصب از مسیر **Settings → Community plugins → Browse** (جستجوی «Git Vault Sync» سپس Install و Enable)، در تنظیمات آن مقادیر زیر وارد می‌شود:

•              **Remote URL:** آدرس HTTPS مخزن، مثلاً https://github.com/your-username/vault.git

•              **Branch:** معمولاً main

•              **Username / Author name / email:** نام کاربری و مشخصات کامیت گیت‌هاب

•              **Personal Access Token:** توکن ساخته‌شده (بند بعدی)

برای اطمینان از صحت اتصال، از Command Palette دستور **Git Vault Sync: Test connection to remote** اجرا می‌شود. برای بکاپ خودکار، دو گزینه کلیدی فعال می‌شوند: **Sync on startup** و **Auto-sync on a timer** (روی ۵ یا ۱۰ دقیقه). با این تنظیم، هر تغییر در هر نود، پوشه یا فایل .md به‌صورت خودکار Commit و Push می‌شود؛ عملکرد یک‌کلیکی «Sync» شامل مرحله‌های Stage ← Commit ← Fetch ← Merge ← Push است.

## ۴.۲ نود Personal Access Token (توکن گیربیار / PAT):

نود اعتبارسنجی مشترک هر دو دستگاه است. مراحل ساخت توکن:

1.              ورود به سایت GitHub ← عکس پروفایل ← **Settings**

2.              **Developer settings** ← **Personal access tokens**

3.              مسیر پیشنهادی: **Fine-grained tokens** ← **Generate new token**؛ انتخاب نام، تاریخ انقضا و محدودکردن توکن فقط به مخزن Vault

4.              در بخش Permissions، دسترسی Repo (کامل همه بخش Repo تیک دار خواهد شد) **Contents: Read and write** اعطا شود

5.              **Generate token** ← کپی فوری توکن (پس از بستن صفحه دیگر قابل مشاهده نیست)

نکته امنیتی: توکن به‌صورت متن ساده در فایل .obsidian/plugins/git-vault-sync/data.json ذخیره می‌شود؛ اگر خود ولت را گیت‌هاب‌پوش کنید حتماً این فایل را در .gitignore قرار دهید و همیشه از توکن با تاریخ انقضا و محدودیت مخزن استفاده کنید.

## ۴.۳ نود Git Vault Sync (اندروید):

همان افزونه روی اپ رسمی اوبسیدین اندروید نصب و فعال می‌شود (موتور پیش‌فرض Auto روی موبایل به‌خودکار **GitHub API engine** را انتخاب می‌کند که فایل‌ها را Blob به Blob منتقل می‌کند و برای ولت‌های بزرگ مناسب است). مقادیر Remote URL، Branch، Username و توکن دقیقاً مثل دسکتاپ پر می‌شود. با فعال‌بودن Auto-sync، گوشی به‌صورت دوره‌ای Pull (دریافت تغییرات دسکتاپ) و Push (ارسال تغییرات خودش) را انجام می‌دهد.
