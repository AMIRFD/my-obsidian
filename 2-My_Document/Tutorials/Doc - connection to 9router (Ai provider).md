# نصب 9router لوکالی
1. ابتدا آن را برروی سیستم لوکالی خود با دستورات نصب کنید (بصورت لوکالی اجرا می‌شود) 
2. برای این کار از دستورات زیر داخل CMD استفاده کنید:
	1. ابتدا node.js باید نصب شود (ویدئوش در سیستم هست)
3. سپس 9router را نصب کنید با npm install -g 9router
4. پس از نصب آن، در CMD بنویسید 9router 
5. برای دسترسی به پنل وب لوکالی web ui (open in browser) را کلیک کنید

# اتصال مدل‌های زبانی به 9router لوکالی
پس از اجرا کردن محیط وب لوکالی آن
	از بخش providers 
	مدلهای زبانی خود را انتخاب کنید مثل Gemini - Openai و...
	==🔴توجه: میتوانید از سایت jarvise you اشتراک بخرید که با openai کار می‌کند==
	برای مثال به سایت Gemini بروید یک api key بسازید و آن را کپی کنید
	در 9router پروایدر gemini را انتخاب کنید و یک اسم (دلخواه) دهید و Key را Paste کنید
	وارد Provider ساخته شده در 9router شوید و در پایین مدلهای مروبط به gemini را نمایش میدهد 
	اضافه کردن مدل های دلخواه از سایت Gemini به 9router: برای این کار از gemini نام هر مدلی که خواستین را کپی کنید و در همان بخش provicerی که ساختین در پایین که مربوط بهه مدل ها میشه add کنید
	به سایت جارویس برید
