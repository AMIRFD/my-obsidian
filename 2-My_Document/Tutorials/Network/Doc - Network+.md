## منظور از ICMP
یک بخش از پروتکل ip است.

در لایه 3 فعالیت داره

 وظیفه داره که در صورت بوجود آمدن خطا به فرستنده پیام (مبدا) خبر بده  یعنی وقتی ping مقصد را در CMD می‌گیری

 اگر ارتباط داشته باشه میگه

Reply from 8.8.8.8: bytes=32 time=129ms TTL=110

اگر نداشته باشه

 request timeout

Destination Host Unreachable

پس اگر خطایی رخ داد، آن را گزارش (ﭘﯿﺎم ﻣﻨﺎﺳﺐ ) میدهد و اگر روتر یا سوئیچی در مسیر نتواند بسته را برساند، یک پیام ICMP به IP مبدأ می‌فرستد و می‌گوید بسته به چه مشکلی خورد.
==🟠**_نکته:_** ICMP**_، شماره پورت ندارد._**==
