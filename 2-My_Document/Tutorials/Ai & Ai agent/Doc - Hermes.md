### 1-1-1     مراحل اتصال Hermes به Telegram

**وارد** Terminal **موجود در** Hermes desktop **شوید و از ترمینال داخلیش یا می‌توانید داخل** Powersheel **با دستور** wsl **پکیج های دستوری** Linux **را نصب کنید و سپس دستورات زیر را اجرا کنید**

**من در ترمینال هرمس این دستورات را اجرا می‌کنم**

hermes gateway setup

**لیست اپ ها و سرویس ها نمایش داده میشه**

**حال عدد 24 را وارد کنید یعنی** Telegram

**جهت اتصال به تلگرام نیاز به موارد زیر داریم**

**ساخت ربات تلگرام (با** @botfather**)**

**نیاز به** Chat id **/** User id**اکانت تلگرام شما (با** userinfobot**@****)**

**خاب توکن را در مرحله توکن و** User ID **را در مرحله مربوط به آن وارد کنید**

**نکته: جهت** Paste **کردن توکن و** UID **از کلیدهای ترکیبی** Shift + ctrl + v **استفاده کنید**

**پس از اتصال یعنی زمانی که مشاهده کردید که نتیجه** Hermes gateway setup **در** Telegram **برابر با** configured **شد **

**وارد ربات خود در تلگرام شوید*
**ابتدا با** /model **ببینید که مدل هوش مصنوعی داخل تلگرام چی انتخاب شده**

 **یعنی:**

**حال اگر مدل رایگان نبود یا مدلی بود که توکن میخورد در همینجا بر روی دکمه** openrouter **کلیک کن و مدل** nvidia/nemotron-3-ultra-550b-a55b:free **را انتخاب کن**

**حال داخل تلگرام پیامی بفرست و** Hermes **جواب خواهد داد**

**اما اگر پیغامی نداد طبق زیر پیش ببروید:**

**نکته کنکوری:** **ارتباط هرمس با تلگرام از طریق** **API** **رسمی تلگرام** (`api.telegram.org`) **است. این آدرس در اینترنت ایران کاملاً مسدود (فیلتر) است وقتی** v2ray **رو روشن می‌کنی معمولاً فقط** **مرورگرها و نرم‌افزارهای دسکتاپ** **متوجه پروکسی سیستم می‌شن. برنامه‌هایی که در پس‌زمینه (مثل پایتون، هرمس یا ابزارهای خط فرمان) اجرا می‌شن، تنظیمات ویندوز رو نادیده می‌گیرن و تلاش می‌کنن** **مستقیم**  **به اینترنت وصل بشن پس با در بسته فیلترینگ برخورد می‌کنن**

.**ممکنه با** vpn**ی (برای من** v2ray **است) که متصل شدی نتوان ارتباط** Hermes **با تلگرام را فراهم کرد یعنی هیچ جوابی نده برای این کار وارد** vpn **خود شده و** Listening port **یا پورت خود را پیدا کنید مثلا** 10808

**داخل پاورشل** wsl **و سپس دستورات زیر را بنویسید:**

**$**env:ALL_PROXY="socks5h://127.0.0.1:10808**"**

**$**env:HTTP_PROXY="socks5h://127.0.0.1:10808**"**

**$**env:HTTPS_PROXY="socks5h://127.0.0.1:10808**"**

Hermes gateway restart

**یا یک فایل** .bat **ایجاد کنید و دستورات زیر را وارد کنید و از این پس این فایل را جهت اجرا کردن**  Hermes **استفاده کنید**

**نکته: در بخش** echo Starting Hermes GUI... **باید آدرس فایل اجرایی** Hermes.exe **را وارد کنید تا برنامه** Hermes **از این آدرس اجرا بشه.**

**نکته: فایل** .bat **را حتما** Run as admin **باز کنید و پس از باز شدن، آن را نبندین (**Hermes **به واسطه آن باز می‌شود)**

@echo off

title Hermes Launcher with Proxy & Gateway Restart

echo Setting up Proxy Environment Variables...

set ALL_PROXY=socks5h://127.0.0.1:10808

set HTTP_PROXY=http://127.0.0.1:10809

set HTTPS_PROXY=http://127.0.0.1:10809

echo Starting Hermes GUI...

start "" "C:\Users\AMIR.AHF\AppData\Local\hermes\hermes-agent\apps\desktop\release\win-unpacked\Hermes.exe"

echo Restarting Hermes Gateway with new proxy session...

call hermes gateway stop

timeout /t 2 /nobreak >nul

call hermes gateway start

echo.

echo ===========================================

echo  Hermes and Gateway are up and running!

echo ===========================================

timeout /t 3 >nul

exit

**پس از کارهای بالا، حتما داخل بات تلگرام خود بنویسید** /start **این کار جادو میکند**

**حال داخل تلگرام پیام دهید جواب خواهید گرفت**

**اگر جواب داد، ولی  جوابش انگلیسی بود، **باید بزنی** /model **و همان مدلی که داخل** Hermes desktop **انتخاب کردی را در اینجا انتخاب کنی.**

**نکته: اگر با خطای مواجه شدید طبق زیر پیش بروید،**

 **اول چک کنید** Provider **سایتش بالا میاد یا نه یعنی آدرس سایت** Provider **مثلا** openrouter.ai **را سرچ کنید اگر بالا نمیامد یا خطای زیر می‌دهد یعنی فیلتر شکن شما مشکل دارد یعنی** **آی‌پیِ فعلی فیلترشکن (اینترنت) شما رو شناسایی و بلاک کرده معمولا روی نت ایرانسل جواب نیست.**
